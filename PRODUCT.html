ForkIQ

Platform and Users

Web panel for administrators managing their GitHub forks.

Product Purpose

Keep forks current with upstream and make synchronization failures actionable.

Capabilities and Constraints

FastAPI and server-rendered Jinja templates. Existing capabilities include GitHub App authentication, discovery, mirror synchronization, history-preserving upstream merges, optional workflow keepalive, repository controls, events, per-repository local/upstream version display (latest tag, short SHA, commit date) and administrator settings.

The redesign preserves server actions, CSRF protection, password-only login, credentials and repository configuration. Real credentials never belong in source, fixtures or documentation.

Brand Commitments

Keep the ForkIQ name and Chinese interface. Follow the user-provided reference at kr.hx10.com, including its centered login: light neutral surfaces, white navigation and green actions.

Product Principles

  • Preserve history and expose errors.
  • Make repository state and available actions easy to scan.
  • Keep desktop and mobile workflows usable without changing synchronization.
